# MelodyFlow 🎵

An ad-free music streaming app that aggregates music from multiple sources.
Built with Flutter, inspired by [BloomeeTunes](https://github.com/HemantKArya/BloomeeTunes).

## Features
- 🚫 **Ad-Free** — Pure, uninterrupted music
- 🎵 **Multi-Source** — Stream from JioSaavn & YouTube Music
- 🎨 **Beautiful UI** — Premium dark theme with glassmorphism
- 🔍 **Smart Search** — Search across all sources simultaneously
- 📱 **Background Play** — Listen while using other apps
- 📋 **Playlists** — Create and manage your playlists
- ❤️ **Favorites** — Save songs you love

## Setup

1. Install [Flutter](https://flutter.dev/docs/get-started/install)
2. Clone the repo:
   ```bash
   git clone https://github.com/yourusername/melody-flow.git
   cd melody-flow
   ```
3. Copy `.env.example` to `.env` and fill in values:
   ```bash
   cp .env.example .env
   ```
4. Install dependencies:
   ```bash
   flutter pub get
   ```
5. Run the app:
   ```bash
   flutter run
   ```

## Security
- No API keys or secrets are committed to the repository
- Environment variables are managed via `.env` (gitignored)
- Builds use `--obfuscate` flag for release
